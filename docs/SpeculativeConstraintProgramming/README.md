## Speculative Constraint Programming
These will be pages for what I call "Speculative Constrained Programming" language design. Here the focus is on prototyping and developing a a programming language that might work as a general purpose programming language in an alternate history timeline, such as an alternate universe where the default lingua franca is Francais.

### Long Term Goal
The long term goal will be documentation seeing such a future happen by testing out such a programming language paradigm, even if its intended for a branch of Roguelikes and Dungeon Crawlers.
